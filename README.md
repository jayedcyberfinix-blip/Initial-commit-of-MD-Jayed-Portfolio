## 🚀 Quick Start (Run Locally)

### Prerequisites
- Node.js (version 18+ or 20+ recommended)
- npm or pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/jayedcyberfinix-blip/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploying to GitHub Pages (Live in 2 Minutes)

This project is pre-configured with **GitHub Actions** and **relative path resolution** (`base: './'`) for effortless 1-click deployment on GitHub Pages!

### Option A: Automatic Deployment via GitHub Actions (Recommended)

1. **Push your code to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit of MD Jayed Portfolio"
   git branch -M main
   git remote add origin https://github.com/jayedcyberfinix-blip/<your-repo-name>.git
   git push -u origin main
   ```

2. **Enable GitHub Pages:**
   - Go to your repository on GitHub.
   - Navigate to **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, select **GitHub Actions**.
   - That's it! GitHub Actions will automatically run `.github/workflows/deploy.yml`, build the site, and publish it at:
     ```
     https://jayedcyberfinix-blip.github.io/<your-repo-name>/
     ```

### Option B: Deploy via `npm run deploy` (`gh-pages`)

If you prefer pushing directly to a `gh-pages` branch:

```bash
npm run deploy
```

Then in **Settings** > **Pages**, choose **Deploy from a branch** and select the `gh-pages` branch.
